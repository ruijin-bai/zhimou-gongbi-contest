# 智眸工笔（参赛版）

施工现场 AI 助手：**AI 先做，人来确认**。一线技术员、安全员用手机说一句、拍一张，Agent 把它整理成施工日志、隐患候选、进度预警、周月报和文书草稿；管理岗在首页只做确认与拍板。产品详细说明与设计口径见 [开发说明.md](开发说明.md)。

> **仿真演示数据声明**：仓库自带的 `data_codex/` 是完全虚构的仿真项目（“仿真公路项目 SIM-ROAD”及两个辅助项目），业主、监理、分包、人名均为虚构，照片为本地程序绘制的示意图，不是现场证据。其中的进度、产值、隐患、AI 采纳率等数字都不代表任何真实项目的成效或试点结果。

## 一条命令看到数据

需要 Python 3.11 及以上。在仓库根目录：

```bash
python -m pip install -r requirements.txt -r requirements-demo.txt
python -X utf8 tools/codex_sim/serve.py
```

浏览器打开 <http://127.0.0.1:8663>。端口被占用时加 `--port 8670` 换一个。

- **登录**：登录页有“开发态快捷登录”，点岗位即可进入，不用输密码。也可以用下表账号手动登录，密码统一为 `SimRoad2026!`。
- **演示日**：服务器时钟固定在 2026-10-11，数据截止 2026-10-04。
- **AI**：默认暂停、不连外部模型，页面上的 AI 文字是数据里预先生成的仿真内容。定时任务关闭。

| 岗位 | 账号 | 看什么 |
|---|---|---|
| 项目经理 | `sim_pm` | 智能管理台：进度、质量、安全的拍板项 |
| 工程主管 | `sim_eng` | 待办、预警、P6 计划、产值、报表 |
| 安全主管 | `sim_safety` | 隐患候选确认、整改闭环、分包履约画像 |
| 技术员（手机） | `sim_zhao` | 随手记、日志、周进度确认 |
| 分包安全员（手机） | `sim_safe_a` | 随手拍、隐患台账 |
| 领导 | `sim_leader` | 项目总览（只读） |
| 系统管理员 | `sim_admin` | 系统概况、模型与审计 |

手机端页面可以把浏览器窗口调窄，或用开发者工具的手机模式查看。

## 说明

- 运行时会在 `data_codex/` 里写会话、日志等文件，这些已被 `.gitignore` 忽略。想恢复初始数据，用 `git checkout data_codex/zhimou.db` 即可。
- 接入真实模型需要自备 Key，放在 `.env`（参照 `.env.example`），不要提交到仓库。
- 测试：`python -m pytest tests`。
